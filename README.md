## Work

I'm an MES engineer at Schaeffler. My work covers shop-floor MES integration, data extraction, and data reporting. 

I also build tools around the MES:
- **Debugging applications** (outside the MES itself) that help the MES team troubleshoot.
- **Review applications** that let Equipment Engineers explore MES data.
- **Admin tools** that speed up the MES team's daily tasks, so we can focus on improving the MES experience.

**Day-to-day stack:** C# · Angular · Python · internal C# MES framework · currently deepening my SQL

## What I build for fun

I write homebrew for the Nintendo DS in C using [BlocksDS](https://blocksds.skylyrac.net/).

### [Lynxibear Valley](https://github.com/Lairlynx/Lynxibear-DS)

A cozy farming game for the DS: tools, crops across four seasons, a town with shops, touch-screen drag-and-drop inventory, streamed music, and SD saves with backup and migration.
